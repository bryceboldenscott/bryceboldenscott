## What I'm building

**[Persefire](https://github.com/bryceboldenscott/persefire-showcase)** — private beta
URL-shortening SaaS: click analytics, QR generation, link-in-bio pages, team workspaces and
scoped API keys. Next.js, Prisma, Postgres and Stripe, with automated security checks in CI.
→ [persefire.com](https://persefire.com)

**[AI Agent Kanban](https://github.com/bryceboldenscott/ai-agent-kanban)** — IBM Dev Day Hackathon 2026
A multi-agent system that classifies incoming work items — incidents, features, tasks — pulls
relevant runbooks, and drafts step-by-step action plans, with human-in-the-loop review before
anything is acted on. IBM watsonx.ai with Granite, and a mock fallback so it runs anywhere.

**[Contract RAG MVP](https://github.com/bryceboldenscott/contract-rag-mvp)** — AI internship
Fully local RAG over synthetic contract data: pgvector retrieval, Gemma 3 4B via Ollama, answers
cited back to their evidence, and refusals when the evidence isn't there. Built solo in
checkpoints, with retrieval and generation evaluated separately and limitations written up
rather than hidden.

**[BASE](https://github.com/bryceboldenscott/base)**
ExecutionOS, the evidence-first project-tracking method I run every AI-assisted build through —
decision and risk registers, Definition-of-Done evidence, recoverable handoffs — packaged as a
Claude Code skill.

**[bryceboldenscott.com](https://github.com/bryceboldenscott/bryceboldenscott.com)**
My portfolio: single-file HTML/CSS/JS, GSAP + Lenis motion, and a Cloudflare Worker that
verifies the captcha server-side and sends mail, voice notes included, through Resend.

**Agent Council** — IBM Dev Day Hackathon 2026, team build
Eight interconnected agents that argue before answering: a planner clarifies the objective, a
critic challenges assumptions, an optimist explores alternatives, a judge synthesizes. Agent
isolation blocks prompt injection across the delegation chain. Built on watsonx Orchestrate.

**L00PS**
A YouTube-to-Notion pipeline: watches channel feeds, pulls each new video, structures it with
Claude, and files it as an organized research page. Python.
